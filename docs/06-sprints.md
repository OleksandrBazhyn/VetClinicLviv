# Розбиття задач на спринти

## Загальна інформація

| Параметр | Значення |
|---|---|
| Тривалість спринту | 1 тиждень |
| Кількість спринтів | 6 |
| Загальна тривалість | 6 тижнів |
| Технологічний стек | React Native + Expo, SQLite, React Native Maps |

---

## Спринт 1 — Ініціалізація проєкту та навігація

**Мета:** Налаштувати проєкт, навігацію, базову структуру екранів

| # | Задача | Критерій виконання |
|---|---|---|
| 1.1 | Ініціалізація Expo-проєкту | `npx create-expo-app` виконано, запускається |
| 1.2 | Налаштування навігації (React Navigation) | Tab-навігація: Список, Карта, Профіль |
| 1.3 | Створення структури папок | `screens/`, `components/`, `db/`, `services/`, `assets/` |
| 1.4 | Розробка макетів (wireframes) | Ескізи всіх екранів погоджено |
| 1.5 | Підключення SQLite (`expo-sqlite`) | БД створюється при першому запуску |
| 1.6 | Створення схеми БД (міграції) | Таблиці: `clinics`, `users`, `reviews`, `services`, `emergency_calls` |
| 1.7 | Завантаження seed-даних з JSON | 10+ клінік завантажуються в SQLite при першому запуску |

---

## Спринт 2 — Список клінік, пошук та фільтрація

**Мета:** Реалізувати введення даних та взаємодію з БД (читання)

| # | Задача | Критерій виконання |
|---|---|---|
| 2.1 | Екран зі списком клінік | FlatList з картками клінік |
| 2.2 | Компонент картки клініки | Назва, адреса, рейтинг, значок 24/7 |
| 2.3 | **Текстовий пошук** (з індексуванням SQLite FTS5) | Пошук за назвою в реальному часі |
| 2.4 | **Панель фільтрів** (чекбокси, радіо-кнопки) | Фільтри: 24/7 toggle, район (picker), рейтинг (slider) |
| 2.5 | Екран профілю клініки | Деталі: контакти, графік, послуги, відгуки |
| 2.6 | **Читання даних з SQLite** | Запити SELECT з фільтрами |
| 2.7 | Читання seed-даних з JSON-файлу | Парсинг та відображення |

## Спринт 3 — Геопросторовий модуль

**Мета:** Реалізувати карту, геолокацію та побудову маршруту (10 балів)

| # | Задача | Критерій виконання |
|---|---|---|
| 3.1 | Підключення `react-native-maps` | Карта відображається |
| 3.2 | Маркери клінік на карті | Всі клініки відображені маркерами |
| 3.3 | Геолокація користувача (`expo-location`) | Синій маркер позиції користувача |
| 3.4 | Відображення найближчих клінік | Сортування за відстанню (Haversine) |
| 3.5 | **Побудова маршруту** | Інтеграція Google Directions API або `expo-linking` до Maps |
| 3.6 | Callout-картка при натисканні маркера | Назва клініки + кнопка «Детальніше» |
| 3.7 | Перехід до профілю клініки з карти | Навігація до ClinicProfile screen |

## Спринт 4 — Авторизація та система відгуків

**Мета:** Реалізувати авторизацію та запис/оновлення даних у БД

| # | Задача | Критерій виконання |
|---|---|---|
| 4.1 | Екран реєстрації (текстові поля) | Форма: ім'я, email, пароль |
| 4.2 | Екран входу | Форма: email, пароль |
| 4.3 | Хешування паролю (bcrypt) | Пароль не зберігається у відкритому вигляді |
| 4.4 | JWT-токен + AsyncStorage | Токен зберігається локально |
| 4.5 | **Запис відгуку в SQLite** | INSERT в таблицю `reviews` |
| 4.6 | **Оновлення рейтингу клініки** | UPDATE `clinics.rating` після нового відгуку |
| 4.7 | **Видалення відгуку** (власний) | DELETE з підтвердженням |
| 4.8 | Екран профілю користувача | Редагування імені та аватару |

**Мета:** Реалізувати аналітичні графіки, роботу з файлами, преміум-функції

|---|---|---|

| 5.3 | Графік 2: кругова — 24/7 vs звичайні | PieChart |
| 5.4 | Графік 3: лінійна — відгуки по місяцях | LineChart |

| 5.7 | Екран екстреного виклику | Форма + передача координат |
| 5.8 | Запис заявки в SQLite + оновлення статусу | INSERT + UPDATE в `emergency_calls` |
